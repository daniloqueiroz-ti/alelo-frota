# Alelo Frota
Projeto desafio Alelo Fullstack Test - Alelo Frota 2020

https://github.com/alelofrota/fullstack-test

# Objetivo
1-Adaptar o layout proposto para ser responsivo, considerando mobile-first para ajudar você pode utilizar frameworks CSS (bootstrap, angular material, clarity, etc) e seguindo o guide e padrões definidos.
2-Integrar os dados na tela utilizando a API criados por você no teste de backend;
3-Implementar busca por placa ao clicar no icone de editar e carregar dados do veiculo;
4-Implementar filtro de busca por placa do veículo e atualizar tabela;
5-Implementar a lógica de paginação para carregar 10 itens por página (5 paginas o total maximo que a API retorna);
6-Deve ser feito utilizando Angular 8+ e pré-processador SCSS;

# O que esperamos ver frontend
-Utilização de rotas;
-Paginação
-Filtro buscando na API
-Layout responsivo (Não precisa seguir o layout tão ao pé da letra, o intuito aqui é testar seu nível de frontend e de backend)

# O que esperamos ver backend

-Teste Unitário

-Tratativas de Erro
-Uso de JPA
